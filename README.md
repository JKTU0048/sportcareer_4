# 🏆 SportCareer

Спортивная платформа для поиска спортсменов, команд и тренеров.

## Возможности

- 🔍 Поиск спортсменов и команд по фильтрам
- 📝 Создание и редактирование профиля
- ⭐ Добавление в избранное
- ✉️ Система личных сообщений
- 🔐 Регистрация и авторизация
- 🔄 Восстановление пароля

## Установка и запуск

### 1. Скачайте проект

Нажмите зеленую кнопку **"Code"** → **"Download ZIP"**

### 2. Распакуйте архив

### 3. Установите Python

Скачайте Python с [python.org](https://python.org) (версия 3.8 или выше)

### 4. Откройте командную строку в папке проекта

- Зажмите **Shift** + правой кнопкой мыши по папке
- Выберите **"Открыть окно команд"** или **"Open in Terminal"**
